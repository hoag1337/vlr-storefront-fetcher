Link your Valorant account

One-time setup on a computer. Takes about a minute.

1Sign in to Riot

Open the Riot sign-in page and log in with your Valorant account.

Open Riot sign-in ↗

Keep that tab open and come back here.

2Copy your session value

Pick your browser and follow the steps to copy one value called ssid.

  1. On the Riot tab, press F12 to open developer tools.
  2. Click the Application tab up top (you may need the » arrow to find it).
  3. On the left, open Cookies → https://auth.riotgames.com.
  4. Find the row named ssid and click it.
  5. The full value appears in the panel below — right-click it → Copy value (or select it all and Ctrl+C).
  1. On the Riot tab, press F12.
  2. Click the Storage tab (use » if it's hidden).
  3. Open Cookies → https://auth.riotgames.com.
  4. Find the ssid row and double-click its Value cell.
  5. Select it all and press Ctrl+C.
  1. Enable the Develop menu once: Safari → Settings → Advanced → tick “Show features for web developers”.
  2. On the Riot tab, press ⌥+⌘+I.
  3. Open the Storage tab → Cookies → auth.riotgames.com.
  4. Click the ssid row and copy its value.

The ssid value is long and looks like random letters. That's correct — copy the whole thing.
